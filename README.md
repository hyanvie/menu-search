# 菜单搜索器 Menu Search

Web开发技术课程作业 —— 使用原生 HTML / CSS / JavaScript 实现的菜品搜索小项目。

## 功能

- 🔍 输入关键词实时搜索菜品名称
- 🏷️ 按分类筛选（主食 / 小吃 / 饮品 / 甜点）
- 🖱️ 点击卡片查看菜品详情（评分、简介、主要食材）
- ❤️ 收藏菜品，收藏列表保存在浏览器本地（localStorage），刷新不丢失
- 📱 响应式布局，适配手机和电脑

## 技术栈

- HTML5
- CSS3（Flexbox / Grid 布局）
- 原生 JavaScript（DOM 操作、事件委托、localStorage）

## 本地运行

直接用浏览器打开 `index.html` 即可，无需安装任何依赖。

也可以用 VS Code 的 Live Server 插件打开，支持实时预览。
